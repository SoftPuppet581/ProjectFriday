# 디자인 기준서 (Codex용)

목표: **"잘 만든 대기업 서비스"처럼 보이는 현대적인 UI.** 화려함이 아니라 **일관성, 절제, 이미지의 힘**으로 만든다.
느낌의 기준은 영상과 이미지가 주인공인 스트리밍/스토어 서비스(Netflix, Apple TV, Steam 신 UI)의 몰입감 + 한국 대기업 앱(토스, 삼성, 카카오)의 정돈된 타이포와 여백이다.

## 1. 현재 화면 진단 (측정한 값)
- 글꼴이 Windows 기본(`Segoe UI`, `Malgun Gothic`)이라 밋밋하다 → 한글 전용 글꼴(Pretendard)로 바꾼다
- 하드코딩된 서로 다른 색상값 **79종**, `styles.css`와 `cinema.css`가 같은 변수(`--surface`, `--line` 등)를 **각각 정의해서 서로 덮어쓴다** → 한 곳(`tokens.css`)으로 합친다
- `border-radius` 값이 **12종**으로 제각각 → 4종으로 줄인다
- 자간이 너무 좁다 (히어로 `-0.065em`, 상세 제목 `-0.055em`). 한글은 `-0.03em`보다 좁히면 글자가 붙어 보인다 → 아래 표대로
- 좋은 점(유지): 다크 + 주황 포인트, 히어로 캐러셀, 스켈레톤/이미지 실패 처리, 반응형 11개 구간, 시맨틱 마크업

## 2. 디자인 토큰 (`frontend/src/tokens.css` 하나로. 다른 CSS에서는 변수만 쓴다)
`main.jsx`에서 **가장 먼저** import하고, `styles.css`/`cinema.css`/`explore.css`/`news.css`의 `:root` 변수 정의는 지운다.

```css
:root {
  /* 글꼴: npm i pretendard 후 main.jsx에서 import 'pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css' (경로는 설치 후 node_modules에서 확인). 오프라인에서도 동작한다 */
  --font: "Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;

  /* 배경 4단계. 위로 갈수록 밝다 */
  --bg-0: #0a0c10;   /* 페이지 */
  --bg-1: #11141a;   /* 카드, 패널 */
  --bg-2: #181c24;   /* 올라온 면(hover, 입력창) */
  --bg-3: #202530;   /* 선택됨, 강조 면 */
  --line: rgb(255 255 255 / .08);
  --line-strong: rgb(255 255 255 / .16);

  /* 글자 3단계 */
  --text-1: #f4f5f7;
  --text-2: #aab0bc;
  --text-3: #7f8694;

  /* 포인트는 주황 하나. 나머지 색은 의미가 있을 때만 */
  --accent: #ffac68;
  --accent-hover: #ffc592;
  --accent-ink: #231409;
  --positive: #5ad39b;   /* 할인율, 무료 */
  --danger: #ff6b6b;

  /* 모서리는 이 4개만 */
  --r-sm: 8px;    /* 칩, 입력창, 작은 버튼 */
  --r-md: 12px;   /* 카드 */
  --r-lg: 20px;   /* 히어로, 모달 */
  --r-pill: 999px;

  /* 간격은 4의 배수만 */
  --s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px; --s-5: 24px; --s-6: 32px; --s-7: 48px; --s-8: 64px; --s-9: 96px;

  /* 그림자 3단계. 테두리(--line)와 함께 쓴다 */
  --e-1: 0 1px 0 rgb(255 255 255 / .04) inset;
  --e-2: 0 8px 24px rgb(0 0 0 / .35);
  --e-3: 0 24px 64px rgb(0 0 0 / .55);

  /* 모션 */
  --ease: cubic-bezier(.2, .7, .2, 1);
  --t-fast: 150ms; --t-base: 240ms; --t-slow: 400ms;
}
```

### 글자 크기 (7단계만. 이 밖의 값은 쓰지 않는다)
| 이름 | 크기 / 줄간격 | 굵기 | 자간 | 쓰는 곳 |
|------|---------------|------|------|---------|
| display | `clamp(40px, 5.2vw, 64px)` / 1.08 | 700 | -0.03em | 히어로 제목 |
| h1 | 40 / 1.2 | 700 | -0.025em | 페이지 제목(뉴스 등) |
| h2 | 28 / 1.3 | 700 | -0.02em | 섹션 제목 |
| h3 | 20 / 1.4 | 600 | -0.01em | 카드 제목, 모달 소제목 |
| body | 16 / 1.6 | 400 | 0 | 본문 |
| small | 14 / 1.5 | 400~500 | 0 | 보조 정보 |
| caption | 12 / 1.4 | 500 | 0.01em | 라벨, 시간, 출처 |
숫자(가격, 날짜, 평점)는 `font-variant-numeric: tabular-nums`. **자간은 -0.03em보다 좁히지 않는다.**

## 3. 구성 요소 기준
- **상단 바**: 높이 64px, `--bg-0`을 72% 투명 + `backdrop-filter: blur(16px)`, 아래 1px `--line`. 현재 메뉴는 아래 2px 밑줄이 아니라 **글자색 `--text-1` + 은은한 면(`--bg-2` pill)**. 검색창은 `--r-pill`.
- **버튼**: 높이 40(기본)/48(주요). 3종만: **Primary**(`--accent` 면 + `--accent-ink` 글자), **Secondary**(`--bg-2` 면 + `--line` 테두리), **Ghost**(면 없음, hover에 `--bg-2`). 모서리 `--r-pill`. hover는 `--t-fast`, 눌렀을 때 `scale(.98)`.
- **칩(플랫폼/장르/태그)**: 높이 28, `--r-pill`, `--bg-2` 면, 글자 small. 선택되면 `--bg-3` + `--line-strong`. 아이콘은 넣지 않는다.
- **게임 카드**: 이미지 16:9(`aspect-ratio`), `--r-md`, 테두리 `--line`. 이미지 아래 제목(h3, 2줄 말줄임), 그 아래 `장르 · 출시일`(small, `--text-2`), 우측 하단에 가격. 배지는 **최대 1개**. hover: 위로 4px + `--e-2` + 이미지 `scale(1.03)`(`--t-base`).
- **히어로**: 박스 카드가 아니라 **좌우 가장자리까지 꽉 찬 전폭**(최대 높이 `min(78vh, 720px)`). 영상/이미지 위에 왼쪽에서 오른쪽으로 `--bg-0` 그라데이션(왼쪽 불투명 → 오른쪽 투명)과 아래쪽 그라데이션. 제목 display, 메타 small, 버튼 2개(Primary "자세히 보기", Secondary "스토어"). 슬라이드 인디케이터는 얇은 **진행 바**(12초 채워지는 가는 선) 형태를 권장.
- **달력 칸**: 날짜 숫자 caption(`--text-3`), 오늘은 숫자 뒤에 `--accent` 동그라미. 칸 안에는 **인기작 표지 1개만 크게(칸을 채우는 16:9)** + 나머지는 `+N` caption. 텍스트 칩 금지. 출시가 몰린 날은 칸 배경만 `--bg-2`로.
- **상세 모달**: `--r-lg`, `--e-3`, 상단 배너(이미지 + 아래 그라데이션) 안에 제목과 평점. 본문은 2단(왼쪽: 설명/스크린샷, 오른쪽: 가격/스토어/정보 패널, `sticky`). 모바일은 1단.
- **가격 블록**: 큰 숫자(h2, tabular-nums), 할인이면 `--positive` 할인율 칩 + 취소선 원가(small, `--text-3`). 가격 미정은 `--text-3`로 **작게**(큰 회색 글씨 금지), 이유 한 줄(콘솔 전용/출시 전).
- **뉴스 카드**: 썸네일 16:9 + 제목(h3 3줄) + 요약(small 2줄) + `매체 · 시간`(caption). 이미지 없는 카드는 `--bg-2` 면 + 매체 이름만 크게.
- **상태 화면**: 로딩은 카드 모양 스켈레톤(shimmer 1.4s), 결과 없음은 아이콘 하나 + 한 줄 + 보조 버튼, 서버 꺼짐은 "서버에 연결할 수 없어요" + 다시 시도 버튼.

## 4. 레이아웃과 정보 구조
- 콘텐츠 폭 최대 1280px, 좌우 여백 데스크톱 32 / 모바일 16. 섹션 사이 `--s-8`(64px) 이상.
- 홈 순서: **히어로 → "이번 주 출시"(가로 레일) → 출시 캘린더(메인) → "주목할 게임"(가로 레일, 평점순) → 최신 뉴스(3~4개)**. 레일은 가로 스크롤(`scroll-snap-type: x mandatory`) + 좌우 화살표.
- 섹션 헤더: 왼쪽 h2, 오른쪽 "전체 보기 →"(Ghost 버튼).
- 모바일: 달력 대신 **날짜별 목록**(날짜 헤더 + 게임 행: 썸네일 56px + 제목 + 가격). 터치 대상은 **최소 44×44px**.

## 5. 하지 말 것 (대기업 느낌을 깎는 것)
- 토큰에 없는 색/간격/모서리 값, `#hex` 직접 쓰기 (필요하면 토큰에 추가하고 이유를 적는다)
- 컴포넌트마다 다른 hover 효과, 3겹 이상 그림자, 장식 그라데이션/글로우 남발
- 글자 크기 7단계 밖의 값, -0.03em보다 좁은 자간, 한 화면에 굵기 4종 이상
- 텍스트 칩이 빽빽한 칸, 이모지, 선 두께가 다른 아이콘 혼용 (아이콘은 lucide 1.75 stroke 하나로 통일, 크기는 16/20/24)
- 카드마다 테두리 + 그림자 + 배경 + 그라데이션을 모두 쓰기 (**테두리 또는 그림자 중 하나**만)
